# 🚀 Job Preparation Web Application

An AI-powered MERN stack application designed to streamline the job preparation process. Users can upload their resumes, generate professional AI-powered resumes, analyze job descriptions, and receive personalized interview reports to improve their chances of landing their desired job.

## ✨ Features

- 🔐 Secure User Authentication (JWT & Cookies)
- 📄 Upload Existing Resume (PDF)
- 📝 AI Resume Generation
- ✨ Create ATS-friendly professional resumes
- 💼 Analyze Job Descriptions
- 🤖 AI-Powered Interview Report Generation
- 📊 Personalized interview questions and feedback
- 📁 Save and Access Previous Interview Reports
- 📱 Responsive and Modern User Interface
- ⚡ Fast performance with React + Vite

## 🚀 Workflow

1. Register or log in.
2. Upload an existing resume or generate a new AI-powered resume.
3. Enter the target job description.
4. Receive:
   - A professional AI-generated resume.
   - A personalized interview report.
   - Job-specific interview questions and preparation insights.
5. Save and review previous interview reports anytime.
